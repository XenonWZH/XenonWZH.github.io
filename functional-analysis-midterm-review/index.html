压缩映像原理

例

\(C([a, b], \rho)\) 是完备的.

证明.

设 \(\{ x_{n} \}\) 是 \((C[a, b], \rho)\) 中的一串 Cauchy 列, 那么 \(\forall \varepsilon > 0\), \(\exists N(\varepsilon)\), 有 \[ \rho(x_{m}, x_{n}) = \max_{a \leq t \leq b} |x_{m}(t) - x_{n}(t)| < \varepsilon. \] 由此, 对 \(\forall t \in [a, b]\), \[ |x_{m}(t) - x_{n}(t)| < \varepsilon, \quad (\forall m, n \geq N(\varepsilon)). \] 固定 \(t \in [a, b]\), 可知 \(\{ x_{n}(t) \}\) 是 Cauchy 列，从而 \(\lim_{ n \to \infty } x_{n}(t)\) 存在. 记该极限为 \(x_{0}(t)\), 则取 \(m \to \infty\) 得到 \(|x_{0}(t) - x_{n}(t)| \leq \varepsilon \ (\forall n \geq N(\varepsilon))\), 故 \(x_{n}(t)\) 一致收敛到 \(x_{0}(t)\), 从而 \(x_{0}(t)\) 连续且在 \(C[a, b]\) 中 \(x_{n}\) 收敛到 \(x_{0}\).

Q.E.D.

定理 (Banach 不动点定理  压缩映像原理)

设 \((\mathscr{X}, \rho)\) 是一个完备的度量空间, \(T\) 是 \((\mathscr{X}, \rho)\) 到自身的一个压缩映射, 则 \(T\) 在 \(\mathscr{X}\) 上存在唯一的不动点.

证明.

\(\forall x \in \mathscr{X}\), 做迭代序列 \(x_{n + 1} = Tx_{n} \ (n = 0, 1, 2, \cdots)\), 因为 \[ \rho(x_{n + 1}, x_{n}) = \rho(Tx_{n}, Tx_{n - 1}) \leq \alpha\rho(x_{n}, x_{n - 1}) \leq \cdots \leq \alpha^{n}\rho(x_{1}, x_{0}), \] 从而对 \(\forall p \in \mathbb{N}\), \[ \rho(x_{n + p}, x_{n}) \leq \sum_{i=1}^{p} \rho(x_{n + i}, x_{n + i - 1}) \leq \sum_{i=1}^{p} \alpha^{n + i - 1}\rho(x_{1}, x_{0}) < \sum_{i=1}^{\infty} \alpha^{n + i - 1}\rho(x_{1}, x_{0}) = \frac{\alpha^{n}}{1 - \alpha}\rho(x_{1}, x_{0}) \to 0. \] (当 \(n \to \infty\), 对 \(\forall p \in \mathbb{N}\) 一致). 因此, \(\{ x_{n} \}\) 是一个 Cauchy 列, 从而有极限. 从 \(x_{n + 1} = Tx_{n}\), 两边取极限 (因 \(T\) 为压缩映射, 故 \(T\) 连续) 得 \[ x^{*} = Tx^{*}, \] 即 \(x^{*}\) 为一不动点. 这个不动点还是唯一的. 事实上, 若 \(x^{*}, x^{**}\) 都是不动点, 则 \[ \rho(x^{*}, x^{**}) = \rho(Tx^{*}, Tx^{**}) \leq \alpha\rho(x^{*}, x^{**}). \] 由此推出 \[ x^{*} = x^{**}. \]

Q.E.D.

例

设函数 \(F(t, x)\) 在 \([-h, h] \times [\xi - \delta, \xi + \delta]\) 上定义、连续并对变元 \(x\) 关于 \(t\) 一致地满足局部 Lipschitz 条件: \(\exists \delta > 0, L > 0\), 使得当 \(|t| \leq h, |x_{1} - \xi| \leq \delta, |x_{2} - \xi| \leq \delta\) 时, 有 \[ |F(t, x_{1}) - F(t, x_{2})| \leq L|x_{1} - x_{2}|, \] 则当 \(h < \min\{ \delta/M, 1/L \}\) 时, 初值问题 \[ \begin{cases} \frac{\mathrm{d}x}{\mathrm{d}t} = F(t, x), \\ x(0) = \xi, \end{cases} \] 在 \([-h, h]\) 上存在唯一解.

证明.

该初值问题即求连续函数 \(x(t)\) 满足 \[ x(t) = \xi + \int_{0}^{t} F(\tau, x(\tau)) \, \mathrm{d}\tau, \] 可看成一个不动点问题. 为此, 考察度量空间 \(C[-h, h]\), 并引入映射 \[ (Tx)(t) = \xi + \int_{0}^{t} F(\tau, x(\tau)) \, \mathrm{d}\tau, \] 则该式等价于求 \(C[-h, h]\) 上的一个点 \(x\), 使得 \(x = Tx\), 即求 \(T\) 的不动点. 我们考察在 \(F(t, x)\) 上加什么条件可以使 \(T\) 成为一个压缩映射. 注意到 \[ \rho(Tx, Ty) = \max_{|t| \leq h} \left| \int_{0}^{t} F(\tau, x(\tau)) \, \mathrm{d}\tau - \int_{0}^{t} F(\tau, y(\tau)) \, \mathrm{d}\tau \right| \leq h \max_{|t| \leq h} |F(t, x(t)) - F(t, y(t))|, \] 因此, 若只要假设 \(F(t, x)\) 对变元 \(x\) 关于 \(t\) 一致地满足局部 Lipschitz 条件, 这时就有 \[ \rho(Tx, Ty) \leq Lh\rho(x, y) \quad (\forall x, y \in \overline{B}(\xi, \delta)), \] 其中 \[ \overline{B}(\xi, \delta) \triangleq \{ x(t) \in C[-h, h] : \max_{|t| \leq h} |x(t) - \xi| \leq \delta \}. \] 当 \(Lh < 1\) 时, \(T\) 在 \(C[-h, h]\) 的子集 \(\overline{B}(\xi, \delta)\) 上是压缩的. 在这里我们把常数 \(\xi\) 看成是 \([-h, h]\) 上恒等于 \(\xi\) 的常值函数. 我们取 \(\mathscr{X} = \overline{B}(\xi, \delta)\), 为了要使 \(T \colon \mathscr{X} \to \mathscr{X}\), 再设 \[ M \triangleq \max\{ |F(t, x)| : (t, x) \in [-h, h] \times [\xi - \delta, \xi + \delta] \}, \] 取 \(h > 0\) 足够小, 以使 \[ \max|(Tx)(t) - \xi| = \max\left| \int_{0}^{t} F(\tau, x(\tau)) \, \mathrm{d}\tau \right| \leq Mh \leq \delta. \] 由于 \((C[-h, h], \rho)\) 是一个完备的度量空间, 而 \(\mathscr{X}\) 又是它的一个闭子集, 因此 \((\mathscr{X}, \rho)\) 还是一个完备的度量空间. 于是由 Banach 不动点定理知, 在上述条件下有唯一的不动点, 即存在唯一的 \(x^{*}\), 使得 \[ x^{*} = Tx^{*}. \]

Q.E.D.

完备化

定理

如果 \((\mathscr{X}_{1}, \rho_{1})\) 是一个以 \((\mathscr{X}, \rho)\) 为子空间的完备度量空间, \(\rho_{1}|_{\mathscr{X} \times \mathscr{X}} = \rho\), 并且 \(\mathscr{X}\) 在 \(\mathscr{X}_{1}\) 中稠密, 则 \(\mathscr{X}_{1}\) 是 \(\mathscr{X}\) 的完备化空间.

证明.

\(\forall \xi \in \mathscr{X}_{1}\), \(\exists x_{n} \in \mathscr{X}\), 使得 \(\rho_{1}(x_{n}, \xi) \to 0 \ (n \to \infty)\). 如果存在 \((\mathscr{X}_{2}, \rho_{2})\) 以 \((\mathscr{X}, \rho)\) 为子空间, 因为 \[ \rho_{2}(x_{n}, x_{m}) = \rho_{1}(x_{n}, x_{m}) \to 0 \quad (n, m \to \infty), \] 所以 \(\exists \hat{\xi} \in \mathscr{X}_{2}\), 使得 \(\rho_{2}(x_{n}, \hat{\xi}) \to 0\). 做映射 \(T \colon \mathscr{X}_{1} \to \mathscr{X}_{2}\), \(T\xi = \hat{\xi}\). 我们先证 \(T\) 是良定的. 令 \(\{ y_{n} \} \subset X\) 满足 \(\rho_{1}(y_{n}, \xi) \to 0\), 并令 \(\bar{\xi} \in \mathscr{X}_{2}\) 满足 \(\rho_{2}(y_{n}, \bar{\xi}) \to 0\), 则有 \[ \rho_{2}(\hat{\xi}, \bar{\xi}) \leq \rho_{2}(\hat{\xi}, x_{n}) + \rho_{1}(x_{n}, y_{n}) + \rho_{2}(y_{n}, \bar{\xi}) \to 0. \] 我们还要证 \(T\) 是等距的. 因为 \(\forall \eta \in \mathscr{X}_{1}\), 又 \(\exists y_{n} \in \mathscr{X}\), 使得 \(\rho_{1}(y_{n}, \eta) \to 0\), 所以 \[ \rho_{1}(\xi, \eta) = \lim_{ n \to \infty } \rho_{1}(x_{n}, y_{n}) = \lim_{ n \to \infty } \rho_{2}(x_{n}, y_{n}) = \rho_{2}(\hat{\xi}, \hat{\eta}). \] 这表明 \((\mathscr{X}_{1}, \rho_{1})\) 是 \((\mathscr{X}_{2}, \rho_{2})\) 的一个子空间.

Q.E.D.

定理

每一个度量空间都有一个完备化空间.

证明.

将 \(\mathscr{X}\) 中的 Cauchy 列分类, 令满足 \[ \lim_{ n \to \infty } \rho(x_{n}, y_{n}) = 0 \] 的两个 Cauchy 列 \(\{ x_{n} \}, \{ y_{n} \}\) 有关系 \(R\). 又有 \(\{ x_{n} \} R \{ y_{n} \}\) 当且仅当 \(\rho(x_{n}, y_{n}) \to 0\), 满足自反性和对称性, 且若 \(\{ y_{n} \} R \{ z_{n} \}\), 则有 \[ \rho(x_{n}, z_{n}) \leq \rho(x_{n}, y_{n}) + \rho(y_{n}, z_{n}) \to 0, \] 得到 \(\{ x_{n} \} R \{ z_{n} \}\), 满足传递性, 故满足该关系的两个 Cauchy 列是等价的. 彼此等价的 Cauchy 列归于同一类且只归一类, 称为等价类. 我们把一个等价类看成是一个元素, 并用 \(\mathscr{X}_{1}\) 表示一切这种元素组成的集合. 在 \(\mathscr{X}_{1}\) 上定义距离: \(\forall \xi, \eta \in \mathscr{X}_{1}\), 任取 \(\{ x_{n} \} \in \xi, \{ y_{n} \} \in \eta\), 令 \[ \rho_{1}(\xi, \eta) = \lim_{ n \to \infty } \rho(x_{n}, y_{n}). \] 我们需要验证该式右端的极限的确存在并且极限值与 \(\{ x_{n} \}, \{ y_{n} \}\) 的选取无关. 有 \[ |\rho(x_{n}, y_{n}) - \rho(x_{m}, y_{m})| \leq \rho(x_{n}, x_{m}) + \rho(y_{n}, y_{m}) \to 0. \] 故 \(\{ \rho(x_{n}, y_{n}) \}\) 是 Cauchy 列, 极限值存在. 令 \(\{ x_{n}' \} \in \xi, \{ y_{n}' \} \in \eta\), 则有 \[ |\rho(x_{n}', y_{n}') - \rho(x_{n}, y_{n})| \leq \rho(x_{n}', x_{n}) + \rho(y_{n}' + y_{n}) \to 0 \] 则有 \(\lim_{ n \to \infty } \rho(x_{n}, y_{n}) = \lim_{ n \to \infty } \rho(x_{n}', y_{n}')\). 我们需要验证 \(\rho_{1}\) 的确是个距离. 正定性和对称性是显然的, 而任取 \(\{ z_{n} \} \in \zeta\), 有 \[ \rho_{1}(\xi, \eta) = \lim_{ n \to \infty } \rho(x_{n}, y_{n}) \leq \varlimsup_{ n \to \infty } (\rho(x_{n}, z_{n}) + \rho(z_{n}, y_{n})) = \rho_{1}(\xi, \zeta) + \rho_{1}(\zeta, \eta). \] 故满足三角不等式. 这样, 我们就证明了 \((\mathscr{X}_{1}, \rho_{1})\) 是一个度量空间.

\(\forall x \in \mathscr{X}\), 我们用 \(\xi_{x} \in \mathscr{X}_{1}\) 表示包含序列 \((x, x, \cdots, x, \cdots)\) 的等价类, 这样的 \(\xi_{x}\) 全体记为 \(\mathscr{X}'\). 显然 \(\mathscr{X}' \subset \mathscr{X}_{1}\), 且映射 \(T \colon x \mapsto \xi_{x}\) 作为 \((\mathscr{X}, \rho) \to (\mathscr{X}', \rho_{1})\) 的映射是满射并有 \(\rho(x, y) = \rho_{1}(Tx, Ty) \ (\forall x, y \in \mathscr{X})\). 因此, \((\mathscr{X}, \rho)\) 和 \((\mathscr{X}', \rho_{1})\) 等距同构, 即有 \((\mathscr{X}, \rho) \subset (\mathscr{X}_{1}, \rho_{1})\). 我们还要证证 \(\mathscr{X}'\) 在 \(\mathscr{X}_{1}\) 中稠密. 任取 \(\xi \in \mathscr{X}_{1}\), 任取 \(\{ x_{n} \} \in \xi\), 则 \(\{ x_{n} \}\) 是 Cauchy 列, 即 \(\forall \varepsilon > 0\), \(\exists N\), 使得 \(\forall n, m > N\), 均有 \(\rho(x_{n}, x_{m}) < \varepsilon\). 于是任意取定 \(m > N\), 则有 \(Tx_{m} = \xi_{m} \in \mathscr{X}'\), 使得 \[ \rho_{1}(\xi, \xi_{m}) = \lim_{ n \to \infty } \rho(x_{n}, x_{m}) < \varepsilon. \]

证明 \((\mathscr{X}_{1}, \rho_{1})\) 是完备的. 设 \(\{ \xi^{(n)} \}\) 是 \(\mathscr{X}_{1}\) 中的 Cauchy 列, 要证 \(\exists \xi \in \mathscr{X}_{1}\), 使得 \[ \rho_{1}(\xi^{(n)}, \xi) \to 0 \quad (n \to \infty). \] 由于 \(\mathscr{X}'\) 在 \(\mathscr{X}_{1}\) 中稠密, \(\forall \xi^{(n)} \in \mathscr{X}_{1}\), \(\exists \bar{\xi}^{(n)} \in \mathscr{X}'\), 使得 \(\rho_{1}(\bar{\xi}^{(n)}, \xi^{n}) < \frac{1}{n}\). 有 \(\{ \bar{\xi}^{(n)} \} \subset \mathscr{X}'\), 则有 \[ \begin{aligned} \rho_{1}(\bar{\xi}^{(n)}, \bar{\xi}^{(m)}) &\leq \rho_{1}(\bar{\xi}^{(n)}, \xi^{(m)}) + \rho_{1}(\bar{\xi}^{(m)}, \xi^{(m)}) + \rho_{1}(\xi^{(n)}, \xi^{(m)}) \\ &\leq \frac{1}{n} + \frac{1}{m} + \rho_{1}(\xi^{(n)}, \xi^{(m)}) \\ &\to 0 & (n, m \to \infty). \end{aligned} \] 故 \(\{ \bar{\xi}^{(n)} \}\) 是 Cauchy 列. 令 \(x_{n} = T^{-1}\xi^{(n)}\), 由于 \(\rho_{1}(\bar{\xi}^{(n)}, \bar{\xi}^{(m)}) = \rho(x_{n}, x_{m})\), 故 \(\{ x_{n} \}\) 是 \(\mathscr{X}\) 中的 Cauchy 列, 存在唯一的 \(\xi \in \mathscr{X}_{1}\), 使得 \(\{ x_{n} \} \in \xi\). 则对 \(\forall n \in \mathbb{N}\), 有 \[ \rho_{1}(\xi^{(n)}, \xi) \leq \rho_{1}(\xi^{(n)}, \bar{\xi}^{(n)}) + \rho_{1}(\bar{\xi}^{(n)}, \xi) < \frac{1}{n} + \lim_{ m \to \infty } \rho(x_{n}, x_{m}). \] 故对 \(\forall \varepsilon > 0\), \(\exists N \in \mathbb{N}\), 使得 \(n, m > N\) 时, 有 \(\rho_{1}(\xi^{(n)}, \xi) < 2\varepsilon\). 即在 \(\mathscr{X}_{1}\) 内有 \(\xi^{(n)} \to \xi\).

综上, 有 \(T \colon \mathscr{X} \to \mathscr{X}'\) 等距同构, \(\mathscr{X}' \subset \mathscr{X}_{1}\) 稠密, 故 \(\mathscr{X}_{1}\) 是 \(\mathscr{X}\) 的完备化空间.

Q.E.D.

列紧集

命题

列紧空间必是完备空间

证明.

设 \((\mathscr{X}, \rho)\) 是一个列紧空间, \(\{ x_{n} \}\) 是其中的一串 Cauchy 列, 不妨设其是一无穷点列. 由列紧性, 存在 \(\{ x_{n} \}\) 的子列 \(\{ y_{n} \}\) 收敛到 \(x_{0} \in \mathscr{X}\). 于是由 Cauchy 列存在收敛子列知 \(x_{n} \to x_{0} \ (n \to \infty)\).

Q.E.D.

定理 (Hausdorff)

为了 (完备) 度量空间 \((\mathscr{X}, \rho)\) 中的集合 \(M\) 是列紧的, 必须 (且仅须) \(M\) 是完全有界集.

证明.

必要性: 用反证法, 若 \(\exists \varepsilon_{0} > 0\), \(M\) 中没有有穷的 \(\varepsilon_{0}\) 网. 任取 \(x_{1} \in M\), \(\exists x_{2} \in M \setminus B(x_{1}, \varepsilon_{0})\); 对 \(\{ x_{1}, x_{2} \} \in M\), \(\exists x_{3} \in M \setminus B(x_{1}, \varepsilon_{0}) \cup B(x_{2}, \varepsilon_{0})\); ...... 对 \(\{ x_{1}, x_{2}, \cdots, x_{n} \} \in M\), \(\exists x_{n + 1} \in M \setminus \bigcup_{k=1}^{n} B(x_{k}, \varepsilon_{0})\); ...... 这样产生的点列 \(\{ x_{n} \} \subset M\) 显然满足 \(\rho(x_{n}, x_{m}) \geq \varepsilon_{0} \ (n \neq m)\), 它没有收敛的子列. 这与 \(M\) 的列紧性矛盾.

充分性: 若 \(\{ x_{n} \}\) 是 \(M\) 中的无限点列, 想找一个收敛子列. 对 \(1\) 网, \(\exists y_{1} \in M\), \(\{ x_{n} \}\) 的子列 \(\{ x_{n}^{(1)} \} \subset B(y_{1}, 1)\); 对 \(\frac{1}{2}\) 网, \(\exists y_{2} \in M\), \(\{ x_{n}^{(1)} \}\) 的子列 \(\{ x_{n}^{(2)} \} \subset B\left( y_{2}, \frac{1}{2} \right)\); ...... 对 \(\frac{1}{k}\) 网, \(\exists y_{2} \in M\), \(\{ x_{n}^{(k - 1)} \}\) 的子列 \(\{ x_{n}^{(k)} \} \subset B\left( y_{2}, \frac{1}{k} \right)\); ...... 最后抽出对角线子列 \(\{ x_{k}^{(k)} \}\), 它是一个 Cauchy 列. 事实上, \(\exists \varepsilon > 0\), 当 \(n > \frac{2}{\varepsilon}\) 时, 对 \(\forall p \in \mathbb{N}\) 有 \[ \rho(x_{n + p}^{(n + p)}, x_{n}^{(n)}) \leq \rho(x_{n + p}^{(n + p)}, y_{n}) + \rho(x_{n}^{(n)}, y_{n}) \leq \frac{2}{n} < \varepsilon. \]

Q.E.D.

定理

完全有界的度量空间是可分的.

证明.

取 \(N_{n}\) 为有穷的 \(\frac{1}{n}\) 网, 则 \(\bigcup_{n=1}^{\infty} N_{n}\) 是一个可数的稠密子集.

Q.E.D.

定理

设 \((\mathscr{X}, \rho)\) 是一个度量空间, 为了 \(M \subset \mathscr{X}\) 是紧的必须且仅须 \(M\) 是自列紧集.

证明.

必要性: 设 \(M\) 是紧集. 先证 \(M\) 是闭集, 只要证 \(M\) 的余集是开集. \(\forall x_{0} \in \mathscr{X} \setminus M\), 因为 \[ M \subset \bigcup_{x \in M} B\left( x, \frac{1}{2}\rho(x, x_{0}) \right), \] 利用 \(M\) 的紧性, \(\exists x_{k} \in M \ (k = 1, 2, \cdots, n)\), 使得 \[ M \subset \bigcup_{k=1}^{n} B\left( x_{k}, \frac{1}{2}\rho(x_{k}, x_{0}) \right). \] 取 \(\delta = \min_{1 \leq k \leq n} \frac{1}{2}\rho(x_{k}, x_{0})\), 则显然有 \(\delta > 0\), 并且 \(\forall x \in B(x_{0}, \delta)\) 有 \[ \rho(x, x_{k}) \geq \rho(x_{k}, x_{0}) - \rho(x_{0}, x) > \delta, \quad (k = 1, 2, \cdots, n). \] 因此, \(B(x_{0}, \delta) \cap M = \varnothing\), 从而 \(M\) 的余集是开集得证. 其次证 \(M\) 是列紧集. 用反证法. 假若有 \(M\) 中的点列 \(\{ x_{n} \}\) 不含有收敛子列, 不妨假定 \(x_{n}\) 是互异的. 对每个 \(n \in \mathbb{N}\), 做集合 \(S_{n} \triangleq \{ x_{1}, x_{2}, \cdots, x_{n - 1}, x_{n + 1}, x_{n + 2}, \cdots \}\), 显然每个 \(S_{n}\) 是闭集 (因为不含收敛子列), 从而每个 \(\mathscr{X} \setminus S_{n}\) 是开集. 但 \[ \bigcup_{n=1}^{\infty} (\mathscr{X} \setminus S_{n}) = \mathscr{X} \setminus \bigcap_{n=1}^{\infty} S_{n} = \mathscr{X} \setminus \varnothing = \mathscr{X} \supset M, \] 由 \(M\) 的紧性, \(\exists N \in \mathbb{N}\), 使得 \(\bigcup_{n=1}^{N} (\mathscr{X} \setminus S_{n}) \supset M\), 即得 \[ \mathscr{X} \setminus \{ x_{n} \}_{n=N+1}^{\infty} \supset M, \] 但这是不可能的, 因为 \(x_{N + 1}\) 属于上式右端而不属于上式左端. 此矛盾说明 \(M\) 是列紧的.

充分性: 设 \(M\) 是自列紧的, 要在 \(M\) 的任一开覆盖中取出有限覆盖. 用反证法, 如果某个开覆盖 \(\bigcup_{\lambda \in \Lambda} G_{\lambda} \supset M\) 不能取出 \(M\) 的有限覆盖. 由于 \(M\) 是自列紧的, \(\forall n \in \mathbb{N}\), 存在有穷的 \(\frac{1}{n}\) 网 \[ N_{n} = \{ x_{1}^{(n)}, x_{2}^{(n)}, \cdots, x_{k_{(n)}}^{(n)} \}, \] 显然 \(\bigcup_{y \in N_{n}} B\left( y, \frac{1}{n} \right) \supset M\). 因此, \(\forall n \in \mathbb{N}\), \(\exists y_{n} \in N_{n}\), 使得 \(B\left( y_{n}, \frac{1}{n} \right)\) 不能被有限个 \(G_{\lambda}\) 所覆盖. 由假定 \(M\) 是自列紧集, 必存在收敛子列 \(y_{n_{k}}\) 收敛到一点 \(y_{0} \in G_{\lambda_{0}}\). 又 \(G_{\lambda_{0}}\) 是开集, 所以 \(\exists \delta > 0\), 使得 \(B(y_{0}, \delta) \subset G_{\lambda_{0}}\). 对此 \(\delta > 0\), 取 \(k\) 足够大, 使得 \(n_{k} > \frac{2}{\delta}\), 并且 \(\rho(y_{n_{k}}, y_{0}) < \frac{\delta}{2}\), 则 \(\forall x \in B\left( y_{n_{k}}, \frac{1}{n_{k}} \right)\), 有 \[ \rho(x, y_{0}) \leq \rho(x, y_{n_{k}}) + \rho(y_{n_{k}}, y_{0}) \leq \frac{1}{n_{k}} + \frac{\delta}{2} < \delta, \] 即 \(x \in B(y_{0}, \delta)\), 从而 \(B\left( y_{n_{k}}, \frac{1}{n_{k}} \right) \subset B(y_{0}, \delta) \subset G_{\lambda_{0}}\). 这与每个 \(B\left( y_{n}, \frac{1}{n} \right)\) 不能被有限个 \(G_{\lambda}\) 所覆盖矛盾.

Q.E.D.

命题

\(C(M, d)\) 是一个度量空间.

证明.

只需验证对 \(\forall u \in C(M)\), 存在着最大值 \(\max_{x \in M} |u(x)|\). 对任意点列 \(y_{n} \in u(M)\), \(\exists x_{n} \in M\), 使得 \(u(x_{n}) = y_{n}\). 由于 \(M\) 是紧的, 从而有子列 \(x_{n_{k}} \to x_{0}, \ k \to \infty\), 而 \(u\) 是连续的, 便有 \(u(x_{n_{k}}) \to u(x_{0}) \in u(M), \ k \to \infty\). 令 \(y_{0} \triangleq u(x_{0})\), 即得 \(y_{n_{k}} = u(x_{n_{k}}) \to y_{0}\), 从而 \(u(M)\) 是紧集. 这蕴含 \(u(M)\) 是有界的数集. 设 \[ \min u(M) = \alpha, \quad \max u(M) = \beta, \] 由闭性推出 \(\alpha, \beta \in u(M)\). 这就证明了 \(\max_{x \in M} |u(x)|\) 的存在性.

定理 (Arzelà–Ascoli)

为了 \(F \subset C(M)\) 是一个列紧集, 必须且仅须 \(F\) 是一致有界且等度连续的函数族.

证明.

因为 \(C(M)\) 是完备的, 所以由 Hausdorff 定理, 为了 \(F\) 是列紧的, 必须且仅须它是完全有界的. 必要性: 因为完全有界集是有界集, 所以 \(F\) 是一致有界函数族. \(\forall \varepsilon > 0\), 要证 \(\exists \delta = \delta(\varepsilon)\), 使得 \(\forall \varphi \in F\) 有 \[ |\varphi(x_{1}) - \varphi(x_{_{2}})| < \varepsilon \quad (\text{当 } \rho(x_{1}, x_{2})) < \delta). \] 因为 \(F\) 的 \(\frac{\varepsilon}{3}\) 网是一个有穷集 \(N\left( \frac{\varepsilon}{3} \right) = \{ \varphi_{1}, \varphi_{2}, \cdots, \varphi_{n} \}\), 对这有穷个函数, 由连续性, \(\exists \delta = \delta\left( \frac{\varepsilon}{3} \right)\), 当 \(\rho(x_{1}, x_{2}) < \delta\) 有 \[ |\varphi_{i}(x_{1}) - \varphi_{i}(x_{2})| < \frac{\varepsilon}{3} \quad (i = 1, 2, \cdots, n). \] 因为 \(\forall \varphi \in F\), \(\exists \varphi_{1} \in N\left( \frac{\varepsilon}{3} \right)\), 使得 \(d(\varphi, \varphi_{i}) < \frac{\varepsilon}{3}\), 所以 \[ \begin{aligned} |\varphi(x) - \varphi(x')| &\leq |\varphi(x) - \varphi_{i}(x)| + |\varphi_{i}(x) - \varphi_{i}(x')| + |\varphi_{i}(x') - \varphi(x')| \\ &\leq 2d(\varphi, \varphi_{i}) + |\varphi_{i}(x) - \varphi(x')| \\ &< \varepsilon & (\text{当 } \rho(x, x') < \delta). \end{aligned} \]

充分性: 设 \(F\) 一致有界且等度连续, 我们要找有穷的 \(\varepsilon\) 网. 由于 \(F\) 是等度连续的, \(\exists \delta = \delta\left( \frac{\varepsilon}{3} \right) > 0\), 使得当 \(\rho(x, x') < \delta\) 时, \(|\varphi(x) - \varphi(x')| < \frac{\varepsilon}{3} \ (\forall \varphi \in F)\). 就此 \(\delta\), 选取空间 \(M\) 上的有穷 \(\delta\) 网 \(N(\delta) = \left\{ x_{1}, x_{2}, \cdots, x_{n} \right\}\). 做映射 \(T \colon F \to \mathbb{R}^{n}\), \[ T\varphi \triangleq (\varphi(x_{1}), \varphi(x_{2}), \cdots, \varphi(x_{n})) \quad (\forall \varphi \in F). \] 记 \(\tilde{F} = T(F)\), 则 \(\tilde{F}\) 是 \(\mathbb{R}^{n}\) 中的有界集. 事实上, 设 \(|\varphi| \leq M_{1} \ (\forall \varphi \in F)\), 则 \[ \left( \sum_{i=1}^{n} |\varphi(x_{i})|^{2} \right)^{\frac{1}{2}} \leq \sqrt{ n } \max_{x \in M} |\varphi(x)| \leq \sqrt{ n }M_{1} \quad (\forall \varphi \in F). \] 从而 \(\tilde{F}\) 是列紧集, 利用 Hausdorff 定理, \(\tilde{F}\) 有有穷的 \(\frac{\varepsilon}{3}\) 网 \[ \tilde{N}\left( \frac{\varepsilon}{3} \right) = \{ T\varphi_{1}, T\varphi_{2}, \cdots, T\varphi_{m} \}. \] 从而 \(\{ \varphi_{1}, \varphi_{2}, \cdots, \varphi_{m} \}\) 是 \(F\) 的 \(\varepsilon\) 网, 这是因为 \(\forall \varphi \in F\), \(\exists \varphi_{i}\), 使得 \(\rho_{n}(T\varphi, T\varphi_{i}) < \frac{\varepsilon}{3}\), 于是取定 \(x_{r} \in N(\delta)\), 使得 \(\rho(x, x_{r}) < \delta\), 有 \[ |\varphi(x) - \varphi_{i}(x)| \leq |\varphi(x) - \varphi(x_{r})| + |\varphi(x_{r}) - \varphi_{i}(x_{r})| + |\varphi_{i}(x_{r}) - \varphi_{i}(x)| \leq \frac{2}{3}\varepsilon + \rho_{n}(T\varphi, T\varphi_{i}) < \varepsilon, \] 其中 \(\rho_{n}\) 表示 \(\mathbb{R}^{n}\) 中的距离.

命题

为了 \(\|\cdot\|_{2}\) 比 \(\|\cdot\|_{1}\) 强, 必须且仅须存在常数 \(C > 0\), 使得 \[ \|x\|_{1} \leq C\|x\|_{2} \quad (\forall x \in \mathscr{X}). \]

证明.

充分性是显然的, 下证必要性. 用反证法. 若该式不成立, 则对 \(\forall n \in \mathbb{N}\), \(\exists x_{n} \in \mathscr{X}\), 使得 \(\|x_{n}\|_{1} > n\|x_{n}\|_{2}\). 令 \(y_{n} \triangleq \frac{x_{n}}{\|x_{n}\|_{1}}\). 一方面 \(\|y_{n}\| = 1\), 另一方面因为 \[ 0 \leq \|y_{n}\|_{2} < \frac{1}{n} \quad (\forall n \in \mathbb{N}), \] 所以 \(\|y_{n}\| \to 0 \ (n \to \infty)\). 又因为 \(\|\cdot\|_{2}\) 比 \(\|\cdot\|_{1}\) 强, 所以 \(\|y_{n}\|_{1} \to 0 \ (n \to \infty)\). 这显然是一个矛盾.

定理

设 \(\mathscr{X}\) 是一个有穷维线性空间, 若 \(\|\cdot\|_{1}\) 与 \(\|\cdot\|_{2}\) 都是 \(\mathscr{X}\) 上的范数, 则必有正常数 \(C_{1}\) 与 \(C_{2}\), 使得 \[ C_{1}\|x\|_{1} \leq \|x\|_{2} \leq C_{2}\|x\|_{1} \quad (x \in \mathscr{X}). \]

证明.

设 \(\dim \mathscr{X} = n\), 这时 \(\mathscr{X}\) 存在一组基: \(e_{1}, e_{2}, \cdots, e_{n}\). 任意一个元素 \(x \in \mathscr{X}\) 有下列唯一的表示: \[ x = \xi_{1}e_{1} + \xi_{2}e_{2} + \cdots + \xi_{n}e_{n}. \] 则每个 \(x \in \mathscr{X}\) 唯一地对应着 \(\mathbb{K}^{n}\) 空间中的一个点 \(\xi = Tx \triangleq (\xi_{1}, \xi_{2}, \cdots, \xi_{n})\). 自然希望建立 \(x\) 在 \(\mathscr{X}\) 中的范数 \(\|x\|\) 与 \(Tx\) 在 \(\mathbb{K}^{n}\) 中的范数 \[ |Tx| = |\xi| \triangleq \left( \sum_{j=1}^{n} |\xi_{j}|^{2} \right)^{\frac{1}{2}} \] 之间的关系. 为此, 考察函数 \(p(\xi) \triangleq \left\| \sum_{j=1}^{n} \xi_{j}e_{j} \right\| \ (\forall \xi \in \mathbb{K}^{n})\). 首先 \(p\) 对 \(\xi\) 是一致连续的. 事实上, \(\forall \xi = (\xi_{1}, \xi_{2}, \cdots, \xi_{n})\) 和 \(\eta = (\eta_{1}, \eta_{2}, \cdots, \eta_{n}) \in \mathbb{K}^{n}\), 由三角形不等式与 Schwarts 不等式有 \[ \begin{aligned} |p(\xi) - p(\eta)| &\leq p(\xi - \eta) \\ &\leq \sum_{i=1}^{n} |\xi_{i} - \eta_{i}| \|e_{i}\| \\ &\leq \left( \sum_{i=1}^{n} |\xi_{i} - \eta_{i}|^{2} \right)^{\frac{1}{2}}\left( \sum_{i=1}^{n} \|e_{i}\|^{2} \right)^{\frac{1}{2}} \\ &\leq |\xi - \eta|\left( \sum_{i=1}^{n} \|e_{i}\|^{2} \right)^{\frac{1}{2}}. \end{aligned} \] 其次, 根据范数的齐次性, 对 \(\forall \xi \in \mathbb{K}^{n} \setminus \{ \theta \}\) 有 \[ p(\xi) = |\xi| \left\| \sum_{j=1}^{n} \frac{|\xi_{j}|}{|\xi|}e_{j} \right\| = |\xi|p\left( \frac{\xi}{|\xi|} \right). \] 注意到 \(\mathbb{K}^{n}\) 的单位球面 \(S_{1} \triangleq \{ \xi \in \mathbb{K}^{n} : |\zeta| = 1 \}\) 是一个紧集, 因此 \(p(\xi)\) 在 \(S_{1}\) 上必有非负的最小值 \(C_{1}\) 与最大值 \(C_{2}\), 即有 \[ C_{1} \leq p(\xi) \leq C_{2} \quad (\forall \xi \in S_{1}). \] 便有 \[ C_{1}|\xi| \leq p(\xi) \leq C_{2}|\xi| \quad (\forall \xi \in \mathbb{K}^{n}). \] 下面证明其中 \(C_{1} > 0\). 用反证法, 假若 \(C_{1} = 0\), 那么 \(\exists \xi^{*} \in S_{1}\) 满足 \(p(\xi^{*}) =0\). 设 \(\xi^{*} = (\xi_{1}^{*}, \xi_{2}^{*}, \cdots, \xi_{n}^{*})\), 即有 \[ \xi_{1}^{*}e_{1} + \xi_{2}^{*}e_{2} + \cdots + \xi_{n}^{*}e_{n} = 0. \] 因为 \(\{ e_{1}, e_{2}, \cdots, e_{n} \}\) 是基, 所以该式蕴含\(\xi^{*} = \theta\). 这与 \(\xi^{*} \in S_{1}\) 矛盾. 我们有 \[ C_{1}|Tx| \leq \|x\| \leq C_{2}|Tx| \quad (\forall x \in \mathscr{X}). \] 如果我们将 \(|Tx|\) 看作是在 \(\mathscr{X}\) 空间中引入的另一范数 \(\|x\|_{T}\), 即 \(\|x\|_{T} \triangleq |Tx| \ (\forall x \in \mathscr{X})\), 那么该式表明 \(\|\cdot\|\) 与 \(\|\cdot\|_{T}\) 是等价的. 于是 \(n\) 维赋范线性空间的范数与其 \(\mathbb{K}^{n}\) 范数等价. 综上, 因为 \(\|\cdot\|_{1}\) 与 \(\|\cdot\|_{2}\) 都与 \(\mathbb{K}^{n}\) 范数等价, 所以 \(\|\cdot\|_{1}\) 与 \(\|\cdot\|_{2}\) 等价.

引理 (Riesz 引理)

证明.

命题

设 \(\mathscr{X}\) 是线性空间, \(A \subset \mathscr{X}\), 那么 \(A\) 的凸包是 \(A\) 中元素任意凸组合的全体，即 \[ \operatorname{co}(A) = \left\{ \sum_{i=1}^{n} \lambda_{i}x_{i} : \sum_{i=1}^{n} \lambda_{i} = 1, \ \lambda_{i} \geq 0, \ x_{i} \in A, \ i = 1, 2, \cdots, n, \ \forall n \in \mathbb{N} \right\}. \]

推论

若 \(C\) 是 \(\mathbb{R}^{n}\) 中的一个紧凸子集, 则必存在正整数 \(m \leq n\), 使得 \(C\) 同胚于 \(\mathbb{R}^{m}\) 中的单位球.

用 \(E\) 表示包含 \(C\) 的最小闭线性子流形. 设其维数是 \(m \ (\leq n)\). 于是在 \(C\) 上必有 \(m + 1\) 个向量 \(e_{1}, e_{2}, \cdots, e_{m}, e_{m + 1}\), 使得 \(e_{i} - e_{m + 1} \ (i = 1, 2, \cdots, m)\) 是线性无关的. 令 \[ e_{0} = \frac{1}{m + 1} \sum_{i=1}^{m + 1} e_{i}. \] 因为 \(e_{0} \in C \subset E\), 所以 \(E - e_{0}\) 是一个 \(m\) 维线性子空间. 于是对 \(\forall y \in E\), 存在唯一的表示 \[ y = \sum_{i=1}^{m} \mu_{i}(e_{i} - e_{0}) + e_{0}, \] 并在 \(E - e_{0}\) 上可引进一个等价范数 \[ \|z\| = \left( \sum_{i=1}^{m} |\mu_{i}|^{2} \right)^{\frac{1}{2}} \quad (z = y - e_{0}, \ y \in E). \] 我们要证: 当该式所表示的 \(\|z\|\) 足够小时, 蕴含 \(y = \sum_{i=1}^{m} \mu_{i}(e_{i} - e_{0}) + e_{0}\) 所表示的 \(y \in C\). 事实上, 因为 \[ y = \sum_{i=1}^{m} \mu_{i}e_{i} + \left( 1 - \sum_{j=1}^{m} \mu_{j} \right)e_{0} = \sum_{i=1}^{m} \left[ \mu_{i} + \frac{1}{m + 1}\left( 1 - \sum_{j=1}^{m} \mu_{j} \right) \right]e_{i} + \frac{1}{m + 1}\left( 1 - \sum_{j=1}^{m} \mu_{j} \right)e_{m + 1}, \] 当 \(|\mu_{j}| \ (j = 1, 2, \cdots, m)\) 足够小时, 该式右端各项系数都是正的, 并且各项系数的总和满足 \[ \sum_{i=1}^{m} \left[ \mu_{i} + \frac{1}{m + 1}\left( 1 - \sum_{j=1}^{m} \mu_{j} \right) \right] + \frac{1}{m + 1}\left( 1 - \sum_{j=1}^{m} \mu_{j} \right) = 1, \] 所以 \(y \in \operatorname{co}\{ e_{1}, e_{2}, \cdots, e_{m}, e_{m + 1} \} \subset C\). 在 \(E - e_{0}\) 上, \(C - e_{0}\) 是一个以 \(\theta\) 为内点的有界闭凸集, 它的 Minkowski 泛函 \(P(z)\) 是 \(E - e_{0}\) 上的一个一致连续、正齐次、次可加泛函, 适合 \(P(z) = 0 \iff z = \theta\). 则 \(\exists\) 常数 \(C_{1}, C_{2} > 0\), 使得 \[ C_{1} \|z\| \leq P(z) \leq C_{2} \|z\| \quad (\forall z \in E - e_{0}). \] 设 \(B^{m}(\theta, 1)\) 是 \(E - e_{0}\) 中的单位球, 若令 \[ \varphi(z) = e_{0} + \begin{cases} \frac{\|z\|z}{P(z)}, & z \neq \theta, \\ 0, & z = \theta, \end{cases} \] 则 \(\varphi \colon B^{m}(\theta, 1) \to C\) 是一个在上同胚.

定理 (Schauder)

设 \(C\) 是 B* 空间 \(\mathscr{X}\) 中的一个闭凸子集, \(T \colon C \to C\) 连续且 \(T(C)\) 列紧, 则 \(T\) 在 \(C\) 上必有一个不动点.

证明.

因为 \(T(C)\) 是列紧集, 所以对 \(\forall n \in \mathbb{N}\), 存在 \(\frac{1}{n}\) 网 \(N_{n} = \{ y_{1}, y_{2}, \cdots, y_{r_{n}} \}\), 即 \[ T(C) \subset \bigcup_{i=1}^{r_{n}} B\left( y_{i}, \frac{1}{n} \right) \quad (y_{i} \in T(C)), \ i = 1, 2, \cdots, r_{n}). \] 记 \(E_{n} = \operatorname{span} N_{n}\), 即 \(E_{n}\) 为由 \(N_{n}\) 张成的有穷维线性子空间. 做 \(T(c) \to \operatorname{co}(N_{n})\) 的映射 \(I_{n}\) 如下: \[ I_{n}(y) = \sum_{i=1}^{r_{n}} y_{i}\lambda_{i} \quad (\forall y \in T(C)), \] 其中 \[ \lambda_{i}(y) = \frac{m_{i}(y)}{\sum_{i=1}^{r_{n}} m_{i}(y)}, \quad m_{i}(y) = \begin{cases} 1 - n\|y - y_{i}\|, & y \in B\left( y_{i}, \frac{1}{n} \right), \\ 0, & y \not\in B\left( y_{i}, \frac{1}{n} \right). \end{cases} \] 因为 \(m_{i}(y) \geq 0\), 并且 \(\forall y \in T(C)\), \(\exists i_{0} \ (1 \leq i_{0} \leq r_{n})\), 使得 \(y \in B\left( y_{i_{0}}, \frac{1}{n} \right)\), 于是 \(m_{i_{0}}(y) > 0\), 所以 \(\sum_{i=1}^{r_{n}} m_{i}(y) > 0 \ (\forall y \in T(C))\). 因此 \(\lambda_{i}(y) \ (1 \leq i \leq r_{n})\) 有定义并满足 \[ \lambda_{i}(y) \geq 0 \quad (1 \leq i \leq r_{n}), \quad \sum_{i=1}^{r_{n}} \lambda_{i}(y) = 1. \] 于是 \(I_{n}\) 在 \(T(C)\) 上有定义, 并且上两式蕴含 \(I_{n}(y)\) 是 \(N_{n}\) 元素的凸组合, 从而 \(I_{n}(y) \in \operatorname{co}(N_{n})\). 此外还有 \[ \begin{aligned} \|I_{n}y - y\| &= \left\| \sum_{i=1}^{r_{n}} y_{i}\lambda_{i}(y) - \sum_{i=1}^{r_{n}} y\lambda_{i}(y) \right\| \\ &= \left\| \sum_{i=1}^{r_{n}} (y_{i} - y)\lambda_{i}(y) \right\| \\ &\leq \sum_{i=1}^{r_{n}} \|y_{i} - 内积空间

命题 (Cauchy-Schwarz 不等式)

设 \((\mathscr{X}, (\cdot, \cdot))\) 是内积空间. 若令 \[ \|x\| = (x, x)^{\frac{1}{2}} \quad (\forall x \in \mathscr{X}), \] 则有 \[ |(x, y)| \leq \|x\| \cdot \|y\| \quad (\forall x, y \in \mathscr{X}), \] 而且该式中的等号当且仅当 \(x\) 与 \(y\) 线性相关时成立.

证明.

不妨设 \(y \neq \theta\), 对 \(\forall \lambda \in \mathbb{K}\) 考察 \[ \|x + \lambda y\|^{2} = \|x\|^{2} + \overline{\lambda}(x, y) + \lambda(y, x) + |\lambda|^{2}\|y\|^{2} \geq 0. \] 取 \(\lambda = -\frac{(x, y)}{\|y\|^{2}}\), 因为 \((x, y) = \overline{(y, x)}\), 所以 \[ \|x\|^{2} - \frac{2|(x, y)|^{2}}{\|y\|^{2}} + \frac{|(x, y)|}{\|y\|^{2}} \geq 0. \] 由此立得原式. 又当 \(x = -\lambda y \ (\lambda \in \mathbb{K})\) 时, 原式中的等号成立. 反之, 若原式中的等号成立, 则上式中的等号成立, 从而 \(x = -\lambda y \ (\lambda \in \mathbb{K})\).

Q.E.D.

命题

在 B* 空间 \((\mathscr{X}, \|\cdot\|)\) 中, 为了在 \(\mathscr{X}\) 上可引入一个内积适合 \((x, x)^{\frac{1}{2}} = \|x\| \ (\forall x \in \mathscr{X})\), 必须且仅须范数 \(\|\cdot\|\) 满足如下平行四边形等式: \[ \|x + y\|^{2} + \|x - y\|^{2} = 2(\|x\|^{2} + \|y\|^{2}) \quad (\forall x, y \in \mathscr{X}). \]

证明.

必要性可通过直接计算得到. 为了证充分性, 令 \[ (x, y) = \begin{cases} \frac{1}{4}(\|x + y\|^{2} - \|x - y\|^{2}) & \text{当 } \mathbb{K} = \mathbb{R}, \\ \frac{1}{4}(\|x + y\|^{2} - \|x - y\|^{2} + i\|x + iy\|^{2} - i\|x - iy\|^{2}) & \text{当 } \mathbb{K} = \mathbb{C}, \end{cases} \] 容易验证它是一个满足原式的内积.

Q.E.D.

定理 (Bessel 不等式)

设 \(\mathscr{X}\) 是一个内积空间. 如果 \(S = \{ e_{\alpha} : \alpha \in A \}\) 是 \(\mathscr{X}\) 中的正交规范集, 那么 \(\forall x \in \mathscr{X}\), 有 \[ \sum_{\alpha \in A} |(x, e_{\alpha})|^{2} \leq \|x\|^{2}. \]

证明.

首先对 \(A\) 的有限子集, 不妨设它们是 \(1, 2, \cdots, n\), 证明 \[ \sum_{i=1}^{n} |(x, e_{i})|^{2} \leq \|x\|^{2}. \] 因为 \[ 0 \leq \left\| x - \sum_{i=1}^{n} (x, e_{i})e_{i} \right\|^{2} = \left( x - \sum_{i=1}^{n} (x, e_{i})e_{i}, x - \sum_{j=1}^{n} (x, e_{j})e_{j} \right) = \|x\|^{2} - \sum_{i=1}^{n} |(x, e_{i})|^{2}, \] 所以上式成立. 由此可见, 对 \(\forall n \in \mathbb{N}\), 适合 \(|(x, e_{\alpha})| > \frac{1}{n}\) 的 \(\alpha \in A\) 至多只有有穷多个, 从而 \((x, e_{\alpha}) \neq 0\) 的 \(\alpha \in A\) 至多有可数多个. 于是原式的左端实际上是至多可数项求和的级数. 再由上是我们有 \[ \sum_{\alpha \in A_{f}} |(x, e_{\alpha})|^{2} \leq \|x\|^{2}, \] 其中 \(A_{f}\) 表示 \(A\) 的任意有限子集. 由此立得原式.

Q.E.D.

推论

假设 \(\mathscr{X}\) 是 Hilbert 空间, 且 \(\{ e_{\alpha} : \alpha \in A \}\) 是 \(\mathscr{X}\) 中的正交规范集. 那么对 \(\forall x \in \mathscr{X}\), 有 \[ \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} \in \mathscr{X}, \] 且 \[ \left\| x - \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} \right\|^{2} = \|x\|^{2} - \sum_{\alpha \in A} |(x, e_{\alpha})|^{2}. \]

证明.

不妨设使得 \((x, e_{\alpha}) \neq 0\) 的可数多个 \(\alpha \in A\) 是 \(1, 2, \cdots, n, \cdots\), 那么 \[ \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} = \sum_{n=1}^{\infty} (x, e_{n})e_{n}, \] 并由 Bessel 不等式可知 \(\sum_{n=1}^{\infty} |(x, e_{n})|^{2}\) 收敛, 因此有 \[ \left\| \sum_{n=m}^{m+p} (x, e_{n})e_{n} \right\|^{2} = \sum_{n=m}^{m+p} |(x, e_{n})|^{2} \to 0 \quad (m \to \infty, \ \forall p \in \mathbb{N}). \] 于是, \(\left\{ x_{m} = \sum_{n=1}^{m} (x, e_{n})e_{n} \right\}\) 是 Cauchy 列, 从而 \[ \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} = \sum_{n=1}^{\infty} (x, e_{n})e_{n} = \lim_{ m \to \infty } x_{m} \in \mathscr{X}. \] 又因为 \(x - \sum_{n=1}^{\infty} (x, e_{n})e_{n} \perp \sum_{n=1}^{\infty} (x, e_{n})e_{n}\), 所以 \[ \left\| x - \sum_{n=1}^{\infty} (x, e_{n})e_{n} \right\|^{2} = \|x\|^{2} - \sum_{n=1}^{\infty} |(x, e_{n})|^{2}. \] 这就是原式.

Q.E.D.

定理

设 \(\mathscr{X}\) 是一个 Hilbert 空间, 若 \(S = \{ e_{\alpha} : \alpha \in A \}\) 是 \(\mathscr{X}\) 中的正交规范集, 则如下三条等价: 1. \(S\) 是封闭的; 2. \(S\) 是完备的; 3. Parseval 等式 \[ \|x\|^{2} = \sum_{\alpha \in A} |(x, e_{\alpha})|^{2} \quad (\forall x \in \mathscr{X}). \] 成立.

证明.

\((1) \implies (2)\). 若 \(S\) 不完备, 则 \(\exists x \in \mathscr{X} \setminus \{ \theta \}\), 使得 \[ (x, e_{\alpha}) = 0 \quad (\forall \alpha \in A). \] 但由封闭性有 \(x = \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} = \theta\), 矛盾. \((2) \implies (3)\). 若 \(\exists x \in \mathscr{X}\) 使 Parseval 等式不成立, 则有 \[ \left\| x - \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} \right\|^{2} = \|x\|^{2} - \sum_{\alpha \in A} |(x, e_{\alpha})|^{2} > 0. \] 于是 \(y \triangleq x - \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} \neq \theta\), 但 \(y \in S^{\perp}\). 这与 \(S\) 完备性矛盾. \((3) \implies (1)\). 联合 Parseval 等式得到 \[ \left\| x - \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha} \right\| = \|x\|^{2} - \sum_{\alpha \in A} |(x, e_{\alpha})|^{2} = 0. \] 因此有 \[ x = \sum_{\alpha \in A} (x, e_{\alpha})e_{\alpha}. \]

Q.E.D.

定理

为了 Hilbert 空间 \(\mathscr{X}\) 是可分的, 必须且仅须它有至多可数的正交规范基 \(S\). 又若 \(S\) 的元素个数 \(N < \infty\), 则 \(\mathscr{X}\) 同构与 \(\mathbb{K}^{N}\); 若 \(N = \infty\), 则 \(\mathscr{X}\) 同构于 \(\ell^{2}\).

证明.

必要性. 设 \(\{ x_{n} \}_{n=1}^{\infty}\) 是 \(\mathscr{X}\) 中的可数稠密子集, 那么其中必存在一个线性无关的子集 \(\{ y_{n} \}_{n=1}^{N} \ (N < \infty \text{ 或 } N = \infty)\), 使得 \[ \operatorname{span}\{ y_{n} \}_{n=1}^{N} = \operatorname{span}\{ x_{n} \}_{n=1}^{\infty}. \] 再对 \(\{ y_{n} \}_{n=1}^{N}\) 应用 Gram-Schmidt 过程, 便构造出一个正交规范集 \(\{ e_{n} \}_{n=1}^{N}\). 又因为 \[ \overline{\operatorname{span}\{ e_{n} \}_{n=1}^{N}} = \overline{\operatorname{span}\{ y_{n} \}_{n=1}^{N}} = \mathscr{X}, \] 所以 \(\{ e_{n} \}_{n=1}^{N}\) 是正交规范基.

充分性. 设 \(\{ e_{n} \}_{n=1}^{N} \ (N < \infty \text{ 或 } N = \infty)\) 是 \(\mathscr{X}\) 的正交规范集, 那么集合 \[ \left\{ x = \sum_{n=1}^{N} a_{n}e_{n} : \operatorname{Re}a_{n} \text{ 与 } \operatorname{Im}a_{n} \text{ 皆为有理数} \right\} \] 是 \(\mathscr{X}\) 中的稠密子集. 从而 \(\mathscr{X}\) 是可分的.

对于正交规范基 \(\{ e_{n} \}_{n=1}^{N} \ (N < \infty \text{ 或 } N = \infty)\), 做对应 \[ T \colon x \mapsto \{ (x, e_{n}) \}_{n=1}^{N} \quad (\forall x \in \mathscr{X}). \] 由此可见, 对应 \(T\) 是 \(\mathscr{X} \to \mathbb{K}^{N}\) (当 \(N < \infty\)) 或 \(\mathscr{X} \to \ell^{2}\) (当 \(N = \infty\)) 的一对一在上线性同构. 此外, \[ (x, y) = \left( \sum_{i=1}^{N} (x, e_{i})e_{i}, \sum_{j=1}^{N} (y, e_{j})e_{j} \right) = \sum_{i=1}^{N} (x, e_{i})\overline{(y, e_{i})} \quad (\forall x, y, \in \mathscr{X}). \] 因此 \(T\) 还是保持内积的. 于是当 \(N < \infty\) 时, \(\mathscr{X}\) 同构于 \(\mathbb{K}^{N}\); 而当 \(N = \infty\) 时, \(\mathscr{X}\) 同构于 \(\ell^{2}\).

Q.E.D.
